# Cherno C++ 教学练习

跟随 YouTube 博主 Cherno 的 C++ 教学视频完成的个人练习。按原文件名保留，文件名中的数字对应学习时记录的视频编号。

| 文件 | 练习内容 |
| --- | --- |
| `cherno_58_59.cpp` | 函数指针、将函数作为参数传递、Lambda 表达式、捕获与 `std::function` |
| `cherno_85.cpp` | 左值、右值、左值引用、右值引用及函数重载 |
| `cherno_89.cpp` | 移动语义与移动构造函数 |
| `cherno_90.cpp` | `std::move` 与移动赋值 |
| `run_command.sh` | 原始编译命令笔记 |

> 保留练习源代码和原有注释，不主动修复错误。部分练习包含多段演示代码、故意错误示例或尚未修复的问题，不能保证直接编译运行。`run_command.sh` 保留原内容，它包含未注释的中文提示，不能直接当作完整 Shell 脚本执行。
